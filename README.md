Получаю список акций или данные по конкретной бумаге (например, Сбербанк).
Получаю последние новости по этой бумаге через РБК.
Отправлять эти данные в ChatGPT (через API).
Получать структурированный вывод: "Что происходит?", "Какие риски в новостях?", "Как диверсифицировано портфолио".
Инструменты:
Язык: Python.
IDE: Cursor.
API: OpenAI API.
