Подключаться к твоему счету T-Invest (в режиме песочницы/Sandbox, чтобы безопасно).
Получать список твоих акций или данные по конкретной бумаге (например, Сбербанк).
Получать последние новости по этой бумаге через API Тинькофф.
Отправлять эти данные в ChatGPT (через API).
Получать структурированный вывод: "Что происходит?", "Какие риски в новостях?", "Как диверсифицировано портфолио".
Инструменты:
Язык: Python.
IDE: Cursor (будем использовать его AI-функции для написания кода).
API: Tinkoff Invest API + OpenAI API.
